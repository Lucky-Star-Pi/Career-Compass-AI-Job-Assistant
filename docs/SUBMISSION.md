## 2. 如何证明可信

1. **数据可追溯。** 每条包含source_url、obtained_at、raw_snapshot、evidence_hash，可定位到[10份证据TXT](../data/raw/MANUAL-20261030-220241.pages/)并重算SHA256。[结构化数据](../data/processed/jobs.json)保留来源与条件原文；哈希证明提交证据的一致性，不证明招聘方此刻仍开放。
2. **判定与解释分离。** 三态由[规则函数](../app/lib/match.ts)计算，画像未确认为unknown、任一明确不符为ineligible、关键未知保持unknown。AI负责解释，卡片判定不由生成文本改写；分项计数聚合已有checks，来源核对不计作个人条件通过。
3. **回答有引用且服务端校验。** [chat-output.ts](../app/lib/chat-output.ts)允许通用问题引用为空；有引用时检查ID与URL成对匹配且属于候选集，并拒绝reply内URL和承诺用语。第七轮改为DeepSeek（15秒）→可选Qwen（10秒）→规则，JSON截断或引用不合格进入下一级；这些闸门不能证明所有自然语言结论正确。
4. **不编造缺失条件。** 没有可用候选或引用无效时不输出成功的岗位推荐，走降级提示；当前无匹配原因未细分。[数据契约](../data/CONTRACT.md)规定页面未写保留unknown，绝不将缺失改写成“不限”；原文明示的长期招聘保留原句，不伪造截止日期。
5. **评委可逐项复核。** 可展开卡片“查看证据”并打开来源链接，对照来源、获取时间、原文与规则解释。[校验入口](../scripts/validate_data.py)及[规则测试](../app/lib/match.test.ts)提供机器检查，已知局限与原始记录缺失在本说明披露，复核不依赖模型自行给出的可信度分数。

6. **公开层与私有层分离。** 岗位列表、筛选、搜索及证据对所有人可见；个人画像与分项判定只在登录后出现。画像未确认时不提供个人“能报/不能报”的结论；简历自动填写会明确标示来源，并允许修改、清空。推荐口径只要求已载明条件通过，未载明项单列待核对，核心三态不改变。

离线规则量化评测见[eval/RESULT.md](../eval/RESULT.md)：判定一致率8/8（100%），已判定项一致率3/3（100%），unknown占比5/8（62.5%）。按指定表运行8例、覆盖4个真实岗位，没有预期eligible的正例；本评测只覆盖规则层，不含模型生成质量，不能外推为完整准确率或报名资格保证。

## 4. 未完成与已知问题

- 简历支持粘贴文本及**浏览器本机PDF文字提取**，文件不上传，服务器仅收到文字；限制5MB/前5页/6000字，不做OCR，扫描件提示粘贴。文字按账号私有存储，可在助手内删除；公开demo为共享账号，勿提交真实简历。
- 画像字段为枚举槽位（学历、专业、届别、城市、证书）；模型只能提出枚举值建议，服务端白名单校验，非法值丢弃并通过dropped_fields回报。普通对话仍生成待确认槽位；简历会自动填写并明确展示“已根据简历填写”，可修改/清空，未识别字段不补猜。模型不能输出或修改规则判定。
- 当前提供注册、登录和7天签名会话；画像与最近20条消息按账号保存在应用目录外的文件中。没有找回密码、邮箱验证或多进程数据库锁。
- 未接数据库，应用只读app/lib/jobs.json；源数据变化需同步副本并重新构建。
- 列表样本10条，筛选与搜索仅覆盖这10条，不代表全站，也不宣称覆盖所有符合条件的岗位。
- 轮询式部署不是标准托管CI；每分钟检查版本，更新存在构建延迟，推送与上线不是同一个时刻。
- 招聘方可能提前关闭报名；显式长期招聘没有具体截止日期，不保证评审期间仍开放，也不证明用户可报名。
- 附件与原始公告正文未系统采集，报名入口、学位、年龄等仍有缺口。
- 当前持久化最近20条消息，含独立账号的连续追问；未实现多会话管理、无限历史或整份简历的通用问答。
- 硕士能否报只写“本科”的岗位仍按unknown处理；专业目录、附加限制、证书缺失需人工确认，没有为提高通过数放宽规则。
- 推荐口径B与核心三态分离：已载明条件均有通过证据才展示条件符合；缺失原文字段单列“公告未载明项”，已载明但画像缺失/解释未支持的条件单列“需补充或核实”。这仍不代表报名资格获准。
- 生成文本可能偏离证据；引用闸门与提示词不能替代逐句事实核查。模型失败走降级，降级不算真实调用成功。
- 模型限额仅单进程内存计数，重启会重置；未配置持久费用监控，账户余额及未来7天额度未由本次工具核验。
- 当前无HTTPS，入口为HTTP + IP + 端口，请勿输入真实简历或敏感信息。
- 早期阶段报告保留当时零数据/来源未核对等历史状态；当前数据以本次结构化文件和提交标记为准，不将历史快照改成事后完成。

## 5. 协作记录交付口径

**未交付原件。** 原生协作记录含本机路径与系统提示词等需要隔离、审查的内容，原件未随公开仓库交付；不得以摘要或哈希清单暗示已交付原始记录。[native-manifest.jsonl](../agent-records/native-manifest.jsonl)已随仓库提供4份原件快照的哈希、字节数、行数及关联提交，它不是岗位证据哈希表，也不是原件内容。

可由参赛者按[交付方案](../agent-records/DELIVERY_PLAN.md)另提供经审查的脱敏副本，export_method必须记为redacted-copy，登记原件SHA256→副本SHA256、删改行号或字段、理由、审查人及时间；目前未制作或交付该副本。本次不读取、不复制、不改写任何native文件。

早期网页规划未独立原文导出、manual-paste无人工原文，已冻结的4份前缀快照之外的后续协作也未随本次提交交付。缺失边界结合[缺失说明](../agent-records/MISSING.md)、[索引](../agent-records/INDEX.md)与manifest理解，不能将后写的验收说明当原始过程记录。
