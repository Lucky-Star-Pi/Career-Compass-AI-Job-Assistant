# 脱敏和交付边界

native 为本次会话源文件的完整行字节前缀快照，不改写原内容。源仍增长，快照不是整场最终导出。
原样记录可能带本机路径、工具上下文或其他受保护内容，默认仅本地保留并被 gitignore 排除。
尚未完成人工逐项隐私审查，不能声称可公开交付。任何敏感原件不得纳入提交包。
交付时对用户可见提示、回复及工具记录另作经过审查的副本，登记其与原件哈希、删减位置及理由。
不公开内部推理或系统上下文；不能将脱敏副本标成未改写 native。
真实简历、电话、邮箱、身份证、住址和密钥不应进入工具输入或新记录；若发现，停止复制该源并记录缺失范围。

人工粘贴通道只接收人工提供的逐轮原文，不自动生成对话。摘要只能写入 notes。
